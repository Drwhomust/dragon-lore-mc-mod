# dragon lore mc mod
 
This is a minecraft mod which adds some lore to dragons.

This includes a new world you can explore and new blocks and resources you can make or use

check the wiki for more info about this mod

this has all the source code for the mod because i am making it open for anyone

to add on or just to see.

https://modrinth.com/project/dragon-lore

# How to complie

You will need to use [MCreator](https://mcreator.net) and the [fabric generator plugin](https://mcreator.net/plugin/64512/mcreator-fabric-generator) as it was made in it. All you really have to do is

open the project in the editor and press "Play test"

or you can make a jar and add it to your minecraft instance.

You can also usee gradle if you want to too!
